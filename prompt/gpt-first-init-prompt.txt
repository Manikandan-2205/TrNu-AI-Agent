# M.AI Tech Solutions AI Service Desk

## Project Vision

Build a production-style AI Service Desk Platform that acts as the first point of contact for customers.

The system should:

* Answer customer questions
* Route requests to the correct department
* Create tickets
* Detect duplicate issues
* Reduce AI costs
* Track token usage
* Store conversation history
* Generate analytics
* Support local Ollama models
* Demonstrate LangGraph, LangChain, RAG, Memory, Context Engineering and AI Agent concepts

---

# Business Problem

Customers contact M.AI Tech Solutions for different reasons:

1. New Project Inquiry
2. SaaS Product Questions
3. Bug Reports
4. Feature Requests
5. Billing Issues
6. Cloud Deployment Support
7. Technical Support
8. AMC Support
9. Existing Project Updates

Currently these requests are manually handled.

The AI Agent will become the intelligent entry point.

# LangGraph Architecture

Node 1

Intent Analyzer

Purpose:

Detect user intent

Output:

* Inquiry
* Bug
* Feature Request
* Pricing
* Complaint

---

Node 2

Department Router

Purpose:

Select destination team

Output:

* Marketing
* Sales
* Technical
* Development
* Cloud

---

Node 3

Knowledge Agent

Purpose:

Search company documents

Sources:

* FAQ
* Product Docs
* Service Docs
* Pricing Docs

---

Node 4

Duplicate Detection Agent

Purpose:

Check similar issues

Example:

User A:

Login not working

User B:

Unable to sign in

Similarity > 90%

Result:

Use existing solution

No LLM call required

---

Node 5

Ticket Agent

Purpose:

Generate ticket

Example:

Ticket Number:

SUP-2026-0012

Priority:

Medium

Department:

Technical Support

---

Node 6

Response Agent

Purpose:

Generate final response

Uses:

* Company knowledge
* Conversation history
* Ticket information

---

Node 7

Analytics Agent

Purpose:

Store metrics

* Tokens
* Cost
* Latency
* Model

# Cost Optimization Features

## Semantic Cache

Store:

Question Embedding

Answer

If similarity > 90%

Return cached answer.

No model call.

---

## Prompt Compression

Store only relevant history.

Avoid sending full chat history.

---

## Context Window Optimization

Send:

Last 5 messages

instead of

Entire conversation
